# Binnacle guides

These guides document Binnacle's behavior in depth. They ship inside the installed package, and
each one is a plain Markdown file in this directory:

- **building-menu-items.md:** the step-by-step build checklist for adding a menu item, its panel,
  and its controls so a new one matches the shipped ones.
- **design-system.md:** the authoritative design and front-end build standard: tokens, themes,
  modular CSS, shared primitives, and interaction conventions.
- **find-places.md:** searching, selecting, and editing Signal K notes and points of interest.
- **marine-radar.md:** the radar provider contract, the chart overlay, controls, zones, and
  failure states.
- **measure.md:** the temporary rhumb-line range and bearing tool.
- **menu-items.md:** behavior, availability, recovery states, and safety rules for every menu
  action.
- **offline-charts.md:** preparing offline chart coverage with Chart Locker: setup, access,
  downloads, troubleshooting, and storage.
- **profiles.md:** named helm setups, what they contain, cross-device synchronization, and device
  privacy.
- **releasing.md:** the maintainer checklist for preparing and publishing a release.
- **tracks.md:** recording, saving, exporting, and retracing segmented voyage tracks.
- **waypoints.md:** dropping, managing, and navigating to server-stored waypoints.
